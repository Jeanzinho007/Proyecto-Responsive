# Proyecto Responsive

## 📌 Descripción

Este proyecto tiene como objetivo demostrar el uso de **Flexbox** y los principios del **Responsive Design** para crear páginas web que se adapten correctamente a diferentes tamaños de pantalla.

El proyecto fue desarrollado utilizando **HTML y CSS**, aplicando diferentes propiedades de Flexbox para organizar y distribuir los elementos de la página.

## 🛠️ Tecnologías utilizadas

* **HTML5** – Para crear la estructura de la página web.
* **CSS3** – Para los estilos, Flexbox y diseño responsive.

## 📱 Características

* Diseño adaptable a diferentes tamaños de pantalla.
* Uso de **Flexbox** para organizar los elementos.
* Diseño pensado para computadores, tablets y celulares.
* Uso de media queries para adaptar el contenido.

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre el archivo `index.html` en tu navegador.
4. Cambia el tamaño de la ventana para comprobar el diseño responsive.
